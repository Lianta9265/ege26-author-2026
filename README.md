# Авторский тренажёр ЕГЭ-26

[Открыть тренажёр](https://lianta9265.github.io/ege26-author-2026/)

128 заданий: 56 пошаговых, 42 «Верно / ошибочно», 30 на полный набор средств связи.

После правильного ответа доступно необязательное объяснение. Ошибочные ответы сопровождаются подсказками; результаты сохраняются в браузере, работает журнал ошибок.

Самостоятельная статическая страница: index.html можно также открыть локально без установки программ и сервера.
